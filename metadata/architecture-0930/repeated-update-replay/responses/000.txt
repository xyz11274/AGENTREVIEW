*** Commit Message
Title: Steer the specialist-review task agent with a full dimension playbook and make memory retrieval budget-driven
- Root cause: the memory instructions (especially ALWAYS_ON_KNOWLEDGE = "Ground every judgment in the Frozen Paper.") gave the task agent almost no behavioral or structural guidance. The retrieved experiences are same-dimension reviews from unrelated papers, so they only supply style — yet nothing told the agent which subcategories each dimension must cover, that weaknesses must be concrete and evidence-anchored, that omissions must be reported, or that it must not hallucinate numbers. Low Thoro./Correct./Complete. scores are consistent with generic, template-shaped or under-specified opinions rather than paper-specific, complete coverage.
- Prompt optimization: rewrote INSTRUCTION_KNOWLEDGE_ITEM, INSTRUCTION_QUERY, INSTRUCTION_RESPONSE and expanded ALWAYS_ON_KNOWLEDGE into a per-dimension subcategory playbook (CLAR/ORIG/QUAL/POL/SIGN) plus behavioral rules: cite SRC anchors, be paper-specific, never invent facts, report omissions, pair weaknesses with actionable revisions, calibrate the recommendation, and treat memory only as a style template.
- Memory design: added `subcategories` fields to KnowledgeItem and Query, stored richer scalar metadata (role/topic/reviewer_name/subcategories), kept each specialist review as one complete retrieval unit, and made read() over-fetch + role-filter without an arbitrary `[:5]` cap so `select_memory_entries(purpose="context")` enforces the budget on whole entries.

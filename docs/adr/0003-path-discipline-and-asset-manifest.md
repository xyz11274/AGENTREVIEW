# ADR-0003：路径纪律与资产身份

- 状态：Accepted
- 日期：2026-08-17
- 最近核验：2026-08-31

## 背景

实验配置、缓存和工件会跨目录复制。把快照目录的绝对路径当作资产身份，会让同一内容在迁移后失去可验证性。

## 决策

1. CLI 边界把用户路径解析为规范绝对路径，内部模块接收已解析路径。
2. 持久化身份由 schema version、内容 SHA-256、逻辑名称和上游身份组成。
3. Asset Manifest 记录输入内容、生成参数、实现身份和依赖关系。
4. 加载器验证内容与 manifest；运行工件记录实际读取的 manifest SHA。
5. 仓库相对路径用于配置可移植性，运行时绝对路径用于审计可定位性。

## 结果

目录迁移保持内容身份稳定。旧快照绝对路径只表达历史运行位置，当前运行通过重新解析和校验建立可信路径。

## 替代方案

仅保存绝对路径的方案把位置当作内容身份；仅保存文件名的方案缺少内容校验。二者都无法形成跨快照的完整 provenance。

# ADR-0017：完整产物准入与仅最终评审 CoCo

状态：2026-09-16 按用户明确要求实施；真实运行验收记录见 `artifacts/shared-acceptance-20260916/`。

保留五角色职责、共享 MemoryProgram、角色独立知识库和 MSTAR 的候选池、softmax 父代采样、轮换反馈及 Champion 选优规则。Qwen3-Embedding-8B 检索角色经验。每次论文审稿从冻结 build 快照创建独立运行状态，读取时发生的状态修改不会写回快照，也不会传给其他论文。

仅将 Meta 生成的最终完整评审交给原版 CoCo。适应度仍为 Table-1 `Paper.`，不是六维 `average`。取消角色单独 CoCo 调用和评分准入要求；五角色原始评审及检索轨迹继续用于反思。本决策取代 ADR-0013、ADR-0015 及旧运行文档中“角色评分用于诊断”的要求。

生成前用服务实际 tokenizer 检查完整输入与预留输出预算，不裁切论文。仅接受 `finish_reason=stop` 且非空的输出；截断响应保留为失败证据，不流入 Meta 或评分。请求有限重试，耗尽后保留失败，不补零。缓存和生成身份绑定新的完整性契约。

候选程序不能通过捕获异常掩盖工具失败。静态检查拒绝不存在的 toolkit 接口；沙箱将别名访问的未知接口报告给宿主。LLM、Embedding 或能力调用失败时，宿主立即使该沙箱会话失效，禁止后续读写和快照发布，并保留基础设施失败与候选错误的归因。MSTAR 负责修复候选源码，人工仅修复公共执行框架。

CoCo 源文件保持不变。适配层保存每个实际请求、token 预算、原始响应和结束原因，在三个阶段追加完整性检查：

- Split 至少一个原版候选完整覆盖输入片段；禁止使用缺失片段回填的降级产物。
- Classify 每个观点都有原版判定为格式有效的模型响应；沿用原版无匹配类别归一化为 `N/A` 的规则。所有尝试均无有效响应而回填的 `N/A` 不准入。
- Judge 所有应评类别及整篇任务齐全，必需评分字段有效；原版允许的 `X` 保留，不用零替代缺失值。

`validate_assessment_receipt()` 同时验证三阶段完整性凭据和原有分数、身份、哈希、队列覆盖及聚合一致性。只有完整评价参与选优。

真实开发验收依次为：已暴露单篇完整链路；真实子代完整评价入池；Champion 冻结；用冻结 Champion 在开发论文重新终评。两个验收凭据都完整且匹配当前实现，才允许启动 pilot。开发终评复用已暴露开发论文，只验证执行链路，不构成未见测试效果证据。

初始 pilot 为 build 4、static 3、rotating 4、3 轮进化，每轮抽 2 篇反馈。历史暴露清单与论文家族审计仍不足以支持正式未见测试主张；准备阶段仅冻结预留 sealed 资产及身份，运行时不把 sealed 论文用于生成、检索或评分，不报告正式泛化结论。

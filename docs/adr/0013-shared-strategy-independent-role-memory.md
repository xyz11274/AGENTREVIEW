# ADR-0013：共享记忆策略进化与五角色独立记忆库

用户确认下一轮采用“一套共享记忆策略参与进化，五个角色各自维护独立 memory 库”。共享策略覆盖记忆组织、构建、检索和使用规则；一个候选版本应用于全部五角色，使用同一候选池和进化谱系，五个角色保持各自职责与记忆资产。

旧实验的 Vector Search 谱系在五角色中均达到各自最高内评分，但最终审稿决策仍有差异，且评分不是标准 CoCo。本决策选择更集中的搜索结构并保留角色知识隔离；实际效果由新开发实验验证。历史依据见[获胜 seed 审计](../audit/20260915/winner_seed_audit.json)。

## 共享与独立的边界

| 对象 | 0915 约定 |
|---|---|
| 记忆规则、候选版本、候选池、lineage | 五角色共用 |
| QUAL、CLAR、SIGN、ORIG、POL 职责 | 各自保持固定 |
| Memory 内容、构建状态、snapshot 与检索范围 | 按角色独立 |
| 候选对应的资产 | 一份共享策略版本，绑定五份角色记忆资产 |
| 初始方案 | Vector Search、LLM Summarizer、Experience Learner 均作为共享初始方案评分 |
| 无 memory | 沿用 ADR-0012：同一审稿流程与其他条件，仅关闭记忆 |
| CoCo Native | 单列基础模型对照 |
| 候选选优对象 | 最终完整评审的标准 CoCo 结果 |
| 五角色单独评分 | 用于诊断和定位问题 |

每个角色用共享规则处理自己的历史评审经验，并从自己的库取经验。相同开发论文可以分别产生五角色评审；角色库独立指各自经验及运行状态独立，论文的开发/测试归属仍严格遵守 ADR-0011。共享代码本身不授予跨角色读取或写入记忆的能力。

## 已确认的选优对象

用户进一步确认“最终评审选优，角色评分用于诊断”。共享候选由其生成的最终完整评审在开发集上的标准 CoCo 表现决定优劣；五个角色的评分帮助定位问题，分别选出的角色 winner 不再组成最终系统。主指标已由 [ADR-0015](0015-paper-fitness-and-separate-results-report.md) 确定为 Table-1 `Paper.`。

## 待确定与迁移边界

算法方向已由 [ADR-0014](0014-mstar-paper-guided-memory-evolution.md) 确定为 M★ 原文的记忆程序种群搜索。

失败处理已按 [ADR-0016](0016-bounded-failure-recovery.md) 确定为有限恢复、完整评价准入和整轮预算耗尽终止。反思材料与实验预算继续确定；S2、Meta/concat、非记忆审稿策略和工作流的可变范围，以及共享程序中的角色专属决策分支继续单独讨论。

一个候选池仍需评价该候选在五角色上的运行，不据此承诺模型调用量降为五分之一。

本决策取代旧设计中五角色分别维护 Program/pool/lineage、分别选出五个 winner 的架构。ADR-0011 的数据隔离和 ADR-0012 的对照定义继续有效。[共享运行器](../SHARED_MSTAR_IMPLEMENTATION.md) 已使用一个候选池、共享程序与五个独立角色快照；最终完整评审决定候选分数，五角色 CoCo 凭据用于诊断。旧角色运行器保留历史协议身份。

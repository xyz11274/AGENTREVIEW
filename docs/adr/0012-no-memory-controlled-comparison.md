# ADR-0012：保持审稿流程一致的无记忆对照

用户确认：无 memory 组保留相同的五个评审角色、汇总流程和其他条件，仅关闭记忆。CoCo 原始 prompt 单独作为基础模型对照。此决定使记忆效果可以在相同审稿流程下比较，取代旧实验中同时改变 Memory、Review Strategy 和 S2 的对照方式。

## 对照定义

| 条件 | 记忆组与对应无记忆组的关系 |
|---|---|
| 五角色、角色职责和审稿策略 | 相同 |
| 最终汇总方式和提示 | 相同，具体 Meta/concat 条件另定 |
| 论文、候选可见正文与数据分区 | 相同 |
| 基础模型、生成设置与非记忆调用预算 | 相同 |
| S2 能力、策略和冻结检索资产 | 相同，具体 S2 条件另定 |
| 评分协议与失败处理 | 相同，具体主指标与失败统计另定 |
| Memory | 记忆组使用对应方案；无记忆组关闭历史记忆的检索和注入 |

三种初始记忆方案与无记忆组分别记录标准 CoCo 初始评分，供进化结果比较。无记忆结果只有在全部非记忆条件相同时才可共用；若后续允许进化改变审稿策略或 S2，则对应无记忆对照也绑定相同的非记忆条件。具体进化范围尚未决定。

CoCo Native Baseline 使用 CoCo 自带审稿提示与提取流程，具有独立实验身份。它衡量整套 AgentReview 与原始提示的表现差异；上述无记忆对照衡量相同 AgentReview 流程中启用记忆的效果。

记忆方案本身的构建、检索、摘要调用和资源消耗随方案记录，资源核算与总预算的具体对齐方式另行讨论。共享运行器已为三种 seed 分别记录配对无 memory 结果；无记忆调用仍通过相同的审稿准备与 S2 策略，并关闭记忆构建经验、查询、读取、摘要及注入。

新对照通过 `memory_enabled` 切换同一程序的记忆操作；三个 seed 及候选的 `plan_review` 必须保持冻结非记忆策略身份。旧 `seeds/no_memory.py` 保留历史 bootstrap 用途。CoCo Native 独立复用标准提示与提取函数，见 [Native 实现](../COCO_NATIVE_BASELINE.md)。

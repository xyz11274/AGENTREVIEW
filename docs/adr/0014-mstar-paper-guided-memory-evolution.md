# ADR-0014：遵循 M★ 原文的记忆程序进化

2026-09-15，用户明确决定“算了，不使用 gepa 了，遵循 mstar 原文思想”。0915 采用 M★ 的反思式记忆程序种群搜索；此前 GEPA 接入、混合前沿和对照实验建议转为已结束的方案研究。算法语义以 [M★ 原文](https://arxiv.org/html/2604.11811v2)为依据，本地 `/data0/xyj/shengao/mstar` 用作可核验的实现参考，论文与代码的差异单独记录。

## 原文机制在本项目中的含义

- **搜索对象**：共享 MemoryProgram 的 Schema、读写 Logic、记忆交互 Instruction。记忆交互指令包括知识提炼、查询构造与返回知识的使用；Task Agent 的固定框架与这些可变指令分别定义。具体接口、工具额度和非记忆审稿指令边界后续细化。
- **种群初始化**：Vector Search、LLM Summarizer、Experience Learner 三种初始方案均评分并进入共享候选池；无 memory 是独立配对对照。
- **静态评价与父代选择**：所有候选使用相同的固定开发评价集，最终完整评审的标准 CoCo Table-1 `Paper.` 聚合为候选分数，主指标定义见 [ADR-0015](0015-paper-fitness-and-separate-results-report.md)；按该分数的 softmax 分布抽取父代。低分有效候选保持被探索的机会。
- **轮换反馈与变异**：按照原文算法，在每轮抽取轮换开发样本并评价本轮选中的父代，以当前轨迹、失败/成功案例及历史变更与分数支持反思，生成代码修改，执行约束检查与有界修复。
- **候选入池**：通过约束并完成有效评价的子代入池，分数用于后续抽样和排序。性能下降与程序运行失败分别处理：有效低分子代保留；修复耗尽仍违反运行约束的程序作为失败尝试存档。
- **候选记忆**：每份新策略按自己的规则从获准来源构建五份角色独立记忆库；继承父代源码与谱系，从新策略重建记忆状态。
- **最终选优**：依据预先冻结的开发评价规则和 `Paper.` 主指标选择一个共享策略，冻结后运行独立最终测试。是否增加开发侧完整复评仍待确定。

原文依据：[搜索空间与种群选择](../../../mstar/paper/sections/method.tex#L15)、[原文算法](../../../mstar/paper/sections/appendix.tex#L99)。论文机制适配到“最终评审 CoCo”这一任务评分；这不等于复现论文中的模型、数据集和数值成绩。

## 延续的实验约定

[ADR-0011](0011-development-coco-and-sealed-test.md) 的严格数据隔离、[ADR-0012](0012-no-memory-controlled-comparison.md) 的无记忆控制、[ADR-0013](0013-shared-strategy-independent-role-memory.md) 的共享策略和五库独立继续有效。模型仍为用户指定的本地 Qwen3.8-27B；角色评分用于诊断，最终完整评审决定候选质量。

开发各用途的实际样本清单、失败预算数值、温度与分数尺度、轮数、样本量、工具预算及 S2/Meta 配置仍需逐项确定。当前反思输入使用开发评分与实际轨迹；直接访问参考评审原文的扩展范围继续讨论。原文参数与本地默认值保留各自来源身份。

## 原文与本地实现差异

本地 mstar 核验版本为 `09a8d34f69588a85fde78b20702d14f056267956`。

1. 原文算法每轮重新抽取轮换样本并评价当前父代；本地 [loop.py](../../../mstar/src/mstar/evolution/loop.py#L302) 优先读取该父代入池时保存的 `reflection_result`。0915 按原文刷新本轮父代的轮换反馈。
2. 原文要求约束修复耗尽仍失败即丢弃；本地 [loop.py](../../../mstar/src/mstar/evolution/loop.py#L473) 在完整评价阶段运行违规的修复循环结束后仍进入无条件 `pool.add`。0915 将“有效评价的低分候选”和“约束失败尝试”分别记录，后者保持失败状态。

共享运行器已落实三 seed 种群、同集 CoCo `Paper.` softmax 父代选择、每轮新 rotating 反馈、完整记忆源码提案、五库重建及有效低分子代入池。Query 指令可在显式 instruction 模式下生成检索查询，记忆响应指令进入审稿上下文；宿主固定角色身份和非记忆审稿策略。当前实现支持 `mutable_scope=memory`，其余可变范围继续讨论。参数从冻结实验协议读取，原文和历史默认值保留各自来源。入口与验证见 [共享 M★ 实现](../SHARED_MSTAR_IMPLEMENTATION.md)。

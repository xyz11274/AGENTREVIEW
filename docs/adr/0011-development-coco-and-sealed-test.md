# ADR-0011：开发阶段标准 CoCo 与严格隔离的最终测试

2026-09-15，用户确认“同意，数据集严格划分，不能混用”。0915 的进化使用独立开发集上的标准 CoCo 评分与反馈；最终测试在系统和实验方案冻结后评价。这个决定使进化目标对齐评价协议，同时保留独立检验能力，取代将所有 CoCo 信息排除在 Evolution 之外的旧边界。

## 已确认的边界

- 开发集与最终测试集具有独立、冻结的样本身份和用途。论文及同一研究工作的其他版本归属同一侧；划分核验覆盖 ID、标题、内容及版本关系，具体近重复识别规则另行确定。
- 每篇论文的参考评审、生成评审、观点、评分、反馈、派生经验和检索资产都保留来源分区。测试材料及其衍生信息仅供冻结系统的最终评测使用；Memory 构建、反思、候选选择和调参使用开发资产。
- 标准 CoCo 规则与开发 CoCo 评分反馈可用于进化。最终测试参考评审、测试评分及反馈与开发流程隔离。开发参考评审由开发评测器消费；Reflector 是否直接读取参考原文尚未决定。
- Review、评分和 Evolution 保持独立阶段，通过已保存的评审和可追溯反馈交接。共享模型或复用评测实现时仍按数据分区区分请求、缓存和结果身份。
- 旧实验已经查看过结果的 1300/902/805 集合属于已暴露历史评测。后续可以用于明确标记的历史诊断；新建封存测试集时排除已暴露测试样本及其同研究版本。
- 本地 Qwen3.8-27B 的模型约束保持生效。

## 仍待确定

开发内部各集合规模、参考评审来源与具体版本审核方法继续确定。评分对象按 ADR-0013 使用最终完整评审，主指标与失败处理分别按 ADR-0015、0016 执行。标准 CoCo 开发评分需要符合协议的参考资产；旧实验的样本量和来源保留历史配置身份。

## 与旧文档的关系

本决策取代 ADR-0008 中“进化只使用 Internal Evaluation、全部 CoCo 仅用于外部测试”的部分，保留阶段分离。它取代 ADR-0010 的数据协议，包括固定来源、固定 1300 测试与仅做最小直接去重的规则。旧设计、架构和运行文档保留为 0831 实现证据；涉及新数据边界时以本 ADR 为准。

运行实现已接入四用途冻结清单、ID/标题/正文/版本及研究 family 隔离、历史暴露排除和来源资产哈希检查。开发阶段仅读取封存身份；最终测试入口在冻结系统与评价版本检查后验证测试正文及参考资产。配置与清单格式见 [实验协议](../SHARED_EXPERIMENT_PROTOCOL.md)。实际新数据清单与实验数值待填写，本轮验证使用测试数据。

# ADR-0015：Paper. 主指标与独立结果汇总

更新（2026-09-16）：按 [ADR-0017](0017-final-only-coco-and-complete-generation.md)，本轮取消角色 CoCo 评分，报告中的角色评分表为空；角色执行轨迹仍保存。

2026-09-15，用户确认采用标准 CoCo 的 Table-1 `Paper.` 作为主指标，并要求集中整理每个 seed 的全部逐篇分数和 CoCo 汇总分数。用户进一步明确“是另外生成，不是初步生成时就整合”：统一报告由独立后处理读取已有结果生成，初次评审和评分流程各自保存原始产物。

## 主指标

共享候选生成最终完整评审，由标准 CoCo 计算逐篇 `Paper.`，再在预定的固定开发评价集上聚合，供 M★ 的 softmax 父代选择和候选排序使用。这里采用 Table-1 的定义，与额外包含 actionability 的 `judge_scores["average"]` 区分。合法不适用值 `X` 按标准协议保留语义。

质量分项、类别 `Average`、`Complete.` 和实际有效分母同时报告；五角色分数用于诊断。评分失败按已接受的 [ADR-0016](0016-bounded-failure-recovery.md) 处理：失败位置保留状态和空分数，正式排名使用完整且可比的评价凭据，成功子集均分保持诊断身份。

持续失败的有限重试、归因、统一重评及终止规则已由用户接受，详见 [系统重审记录第 3.1 节](../audit/20260915/SYSTEM_REASSESSMENT.md#31-持续失败的终止与恢复规则已接受)。标准 CoCo 与本 ADR 定义的主指标和报告职责保持一致。

依据：[CoCo Paper. 聚合](../../../CoCoReviewBench/src/evaluation/_4_evaluation.py#L906)、[指标核验](../audit/20260915/SYSTEM_REASSESSMENT.md#52-最终评审的-coco-主指标核对)。

## 独立汇总的边界

```text
评审生成 → 原始评审文件
标准 CoCo 评分 → 原始逐篇评分和汇总文件
                         ↓ 之后独立运行
              结果汇总工具 → 新的报告与明细表
```

汇总工具以原始结果文件和样本清单为输入，另外写出可重复生成的派生报告。它不调用评审模型、Judge 或反思模型，不补跑缺失实验，不改写原始评审、评分或正式候选排名。报告生成失败不影响已完成的评审和评分；追加结果后可以重新运行汇总。

同一分区、方案、运行和评分协议下，汇总必须能由逐篇结果按标准公式重算。重算值与原始汇总不一致时单独报告差异，保留原始数值与来源以供核查。

原始评分仍需保存足够的逐篇数据与失败状态，保证后处理能够完整还原。这属于基础结果记录，与在首次生成流程中拼装统一报告是不同职责。

## 统一报告包含什么

| 部分 | 内容 |
|---|---|
| 方案总表 | 三个初始 Memory Seed、无 memory 对照、CoCo Native、进化候选与最终获选策略；按数据分区、运行和评价协议分别汇总 |
| 逐篇明细 | 每个方案在预定评价集合中的全部 paper ID、标题、`Paper.`、CoCo 分项、适用性、成功或失败状态、失败阶段与原因、原始文件位置 |
| 每个 seed 的 CoCo 成绩 | 每种初始方案独立的标准指标汇总、预定篇数、成功篇数、失败篇数及每项有效分母 |
| 进化过程 | 候选 ID、初始 seed 谱系、父代、轮次、程序版本、逐篇与聚合成绩；初始 seed 与其后代分别展示 |
| 角色诊断 | 五角色已有评分与诊断，标明角色和评价协议，保持与最终评审成绩的区别 |
| 缺失与来源 | 尚未生成、未评分、失败、合法不适用分别表达；记录源文件身份与本次报告输入范围 |

“全部论文”指该方案在实验协议中预先约定的评价清单，包括未成功产出评分的条目；汇总步骤不扩大模型实验范围。

“整理到一起”指统一入口和表格。开发构建数据、固定评价集、轮换反馈集和封存测试继续保留各自身份与分母；测试开放前的开发报告仅访问开发产物。方案冻结且测试完成后，最终报告可分区展示两侧结果，测试分数不回流到进化选择。

## 历史结果与实现状态

0831 的单角色整体 1–5 内评分使用历史协议身份，不能转写为标准 CoCo；五个不同获选角色策略组合产生的完整评审成绩，也不能标成某一个初始 seed 的 CoCo 成绩。历史没有生成的 seed CoCo 结果应标明缺失，并在新实验按已确定协议获取。

标准 CoCo 适配与独立报告入口已实现。`experiment-report` 读取运行器保存的来源清单，另外生成 `report.json`、`papers.csv`、`variants.csv`、`role_diagnostics.csv` 和说明文件；缺失、失败与合法不适用均保存独立状态，原汇总与重算差异分别展示。具体格式见 [独立报告](../EXPERIMENT_REPORT.md)。实际数据与实验参数继续确定，本轮没有生成新的模型实验成绩。

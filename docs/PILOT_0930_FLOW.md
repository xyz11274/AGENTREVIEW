# 0930 小规模实验输入输出

当前运行入口与本机模型配置见[运行说明](PILOT_0930.md)，完整源码职责与根因修复见[架构说明](ARCHITECTURE_0930.md)。实时阶段见 [pilot-state.json](../artifacts/pilot-0930-local/pilot-state.json)，逐轮效果见[自进化逐轮报告](../artifacts/pilot-0930-local/report/自进化逐轮报告.md)。

| 流程 | 输入 | 输出 |
|---|---|---|
| 数据准备 | 既有开发论文与家族身份 | 4 篇构建、3 篇固定、5 篇轮换、3 篇测试论文及完整资产 |
| 经验构建 | 构建论文、五角色身份、API 模型 | 完整角色审稿经验 |
| 记忆构建 | MemoryProgram 与各角色经验 | 五份独立记忆快照 |
| 审稿 | 完整论文、角色身份、该角色的记忆 | 五份 Specialist Review 和一份 Final Review |
| CoCo 评分 | Final Review、原版参考、Split/Classify/Judge | 原版指标、Paper. 成绩与回执 |
| M★ 反思 | 父程序、轮换反馈、完整轨迹和谱系 | 修改说明与程序差异文本 |
| 程序变异 | 父 Python 源码与差异 | 顺序应用后的候选 Python 程序 |
| 验证修复 | 候选程序与实际宿主接口 | 验证轨迹、修复输出、可执行候选或明确失败 |
| 候选比较 | 同一固定集上的父子完整成绩 | 每篇差值、均值、胜平负和 Champion 状态 |
| 独立测试 | 已冻结系统与封存论文 | 最终配对效果 |

每轮进化的衡量依据是同一评价 epoch、同一固定论文集的完整 CoCo `Paper.` 成绩。轮换集成绩用于反思输入，封存集成绩用于搜索完成后的独立比较。模型修改声明、实际源码变化、执行验证和评分结果分别保存。

失败候选的报告指向最后一次实际验证的程序及其错误。反思轨迹保留每次原始响应和源码 diff，便于逐轮解释自进化的改动与效果。
